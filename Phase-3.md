# Phase 3 - Create Users and Security Groups
Now that the OU structure is created, we will now create the users belonging to their designated department and assign specific Security Groups(RBACs) to each department. This will ensure that each department have the correct permissions based on their role in the company. This is important because this sets boundaries to groups with least privilege access making the environment more secure and manageable.
