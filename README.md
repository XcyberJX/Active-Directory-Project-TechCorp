# TechCorp Company Project 
## Overview
TechCorp is a growing managed service provider company that help other companys and clients with technical related issues. I will act as a System Administrator to ensure the company's computer servers and systems run safe and efficiently. The goal is to create an AD structure with standardized OUs, users with proper group memberships, and with basic implemented security policies.

## 5 Phases
This project will consist of 5 phases with each ensuring a smooth and efficient setup
   * Phase 1: Lab Environment Setup  

   * Phase 2: Design the OU Hierarchy

   * Phase 3: Create Users and Security Groups

   * Phase 4: Key Tasks to Implement

   * Phase 5: Testing the setup
